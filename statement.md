## Problem Statement
Managing student records and academic marks manually can be time-consuming and may lead to calculation and record-keeping errors. The proposed Student Management System provides a simple Java-based solution for storing student details, managing marks, calculating academic performance, generating reports, and storing records.

## Scope
The project covers student registration, searching and deleting students, marks management, grade calculation, report generation, file storage, and database storage using JDBC.

## Target Users
- Students
- Teachers
- Academic staff

## High-Level Features
1. Student management
2. Marks and grade management
3. Performance report generation
4. File storage
5. JDBC database storage
6. Exception handling and input validation
